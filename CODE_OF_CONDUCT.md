# Code of Conduct

The full text is published at
<https://bioinformaticshub.github.io/code-of-conduct/> and kept in
[`code-of-conduct.md`](code-of-conduct.md) in this repository.

In short: Bioinformatics Hub is a space for learning. Be welcoming, assume good faith,
answer beginners' questions without condescension, credit other people's work, and never
post identifiable patient data. Harassment of any kind is not tolerated, in the Slack
workspace, in this repository or at hub events.

Report concerns privately to the steering committee on Slack rather than in a public issue.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 1.4.
