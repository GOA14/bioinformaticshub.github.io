# Bioinformatics Hub brand assets

The mark is the outline of **Nigeria carrying the community network**: a node for each
major university or research city, linked through Abuja, the amber hub node. The outline
is real geometry, simplified from the open `datasets/geo-countries` boundary file to 158
vertices, not traced by hand.

Everything here is generated by [`scripts/make_logo.py`](../../scripts/make_logo.py):

```bash
python scripts/make_logo.py          # SVG only
python scripts/make_logo.py --png    # SVG + PNG + favicon.ico  (needs cairosvg, pillow)
```

Edit the palette, the city list or the links at the top of that script and re-run; do not
hand-edit the files in `svg/`, they will be overwritten.

## Palette

| Role | Hex | Use |
| --- | --- | --- |
| Hub green | `#008751` | Primary. The green of the Nigerian flag. |
| Deep green | `#00603a` | Gradients, hover states, dark headings. |
| Light green | `#6fc79b` | Subtitles and links on dark backgrounds. |
| Hub amber | `#c98a00` | The Abuja node and sparing accents only. |
| Ink | `#0f1f18` | Body text, dark backgrounds. |
| Paper | `#ffffff` | Reversed mark, page background. |

## Which file to use

| Need | File |
| --- | --- |
| Website header, documents | `svg/mark-primary.svg` |
| Slack / GitHub / X avatar | `png/icon-512.png` (or `svg/icon-tile.svg`) |
| Browser tab | `svg/icon-favicon.svg`, `png/favicon.ico` |
| Letterhead, slide title, banner | `svg/lockup-horizontal.svg` |
| Dark slide or poster | `svg/lockup-horizontal-dark.svg` |
| Poster, T-shirt, roll-up banner | `svg/lockup-stacked.svg` |
| Single-colour print, embroidery, stamp | `svg/mark-mono-black.svg`, `svg/mark-mono-white.svg`, `svg/mark-mono-green.svg` |
| Link preview on X, LinkedIn, WhatsApp | `png/social-card-1280x640.png` |

The `mono` marks knock the network out of the silhouette as true transparency, so they
work on any background colour in one ink.

## Using it well

- **Clear space.** Keep free space of at least the height of the amber hub node on all
  four sides of the mark or lockup.
- **Minimum size.** Mark: 24 px tall on screen, 8 mm in print. Below that use
  `icon-favicon.svg`, which drops the network and keeps only the silhouette.
- **Do not** re-colour the mark outside this palette, stretch it, rotate it, add a drop
  shadow, place the colour mark on a mid-green background, or re-set the wordmark in
  another typeface at a different size relative to the mark.
- **Wordmark type** is DejaVu Sans Bold, converted to outlines so the files render
  identically on any machine. To move to Inter or Source Sans, change `WORDMARK_FONT` in
  `scripts/make_logo.py`, install the font and re-run.

## Where it is already wired in

- `assets/img/logo.svg` -- site header
- `assets/img/favicon.svg`, `favicon.ico`, `assets/img/apple-touch-icon.png` -- browser and phone icons
- `assets/img/social-card.png` -- `image:` in `_config.yml`, used by jekyll-seo-tag for link previews
- `#008751` is `--green` in `assets/css/main.css`
