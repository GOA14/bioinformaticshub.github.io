## The short version

Bioinformatics Hub is a community of scientists, students and researchers in Nigeria who
work with biological data. It started as a Slack workspace in {{ site.founded }} and this
site is its public home: a members directory, an events calendar, a blog, and a set of
resources, all maintained in the open on GitHub.

## Aims

- Facilitate the sharing of bioinformatics knowledge across Nigerian institutions.
- Lower the barrier for biologists and clinicians who want to start analysing their own data.
- Make the Nigerian bioinformatics community visible to itself and to the wider world.
- Circulate training, funding and career opportunities quickly and fairly.

## How it is run

Everything on this site lives in a public repository. Members add themselves, write posts,
list events and fix mistakes by opening issues and pull requests. The steering committee
reviews contributions and looks after the Slack workspace; the role is voluntary and open.

**We are looking for volunteers to serve as administrators from Nigerian institutions.**
If you would like to help run the hub, say so in an
[issue](https://github.com/{{ site.repository }}/issues/new) or on Slack.

## Origins

The Slack workspace was created by Umar Ahmad in {{ site.founded }}, while he was a PhD
student at Universiti Putra Malaysia and the Malaysia Genome Institute, as a place for
Nigerian scientists to discuss bioinformatics. It has since grown into a general-purpose
community for anyone in Nigeria working with omics and computational biology.

## Reusing this site

The code is MIT licensed and the content is CC BY 4.0. If you want to run something similar
for your own community, fork the repository and edit `_config.yml` and `_data/`. The site
layout follows [NorthernBUG](https://northernbug.github.io/), whose members-as-a-YAML-file
approach this one borrows.
